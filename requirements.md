# Phase 2 — Requirement Analysis
## Functional
User registration/login, dashboard, three planners, budget input, preferences, optional outfit upload, recommendations, history and shopping links.
## Non-functional
Responsive UI, readable code, environment-variable secrets, graceful API failure and testability.
## Technologies
Python, FastAPI, Jinja2, HTML/CSS/JavaScript, Google Gemini, optional Pillow/image processing, pytest.
## Inputs
Budget, user preferences and optional jewelry outfit image.
## Outputs
Budget allocation, recommendations and external search links.
